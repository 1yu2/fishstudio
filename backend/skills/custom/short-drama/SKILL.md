# 短剧创作工作流

## 概述

适用场景：用户要创作竖屏短剧 / 多集系列剧情视频（每集通常 30 秒到 3 分钟，3-10 个镜头）。
使用系列视频引擎的高层工具完成：项目 → 分镜 → 角色资产 → 审批 → 批量生成 → 整集渲染。

## 创作方法论

### 分集钩子结构

- **开头 3 秒定生死**：第一集第一镜必须是冲突、悬念或强情绪画面，不要铺垫。
- **每集一个核心冲突**：一集只推进一个矛盾，结尾留钩子（反转预告、危机、悬念台词）引导看下一集。
- **结尾钩子类型**：新信息揭露、关系反转、危机降临、未说完的台词。避免平淡收尾。
- **节奏**：情绪高点放在每集 70% 处，随后快速收束 + 钩子。

### 角色设定要点

- 主角不超过 3 个，每个角色一句话动机（"要什么、怕什么"）。
- 角色外观描述固定化（发型、服装、年龄感、标志性道具），写进角色资产，所有镜头复用同一资产版本。
- 音色与角色绑定：同一角色的全部对白使用同一音色资产。

### 分镜规则

- **每镜头 5-10 秒**：短于 5 秒观众看不清，长于 10 秒节奏拖沓。
- **对白时长与镜头时长匹配**：中文正常语速约 4-5 字/秒，镜头内的对白字数不要超过镜头时长能容纳的量；长对白拆成多个镜头（正反打）。
- **竖屏构图（9:16）**：人物居中偏上，重要表情用中近景/特写；避免宽幅横移调度；字幕区域下方 1/4 保持干净。
- 空镜（环境、转场）控制在 3-5 秒。
- 每个镜头写清：画面描述（visual_prompt）、运镜（camera）、对白轨（dialogue_tracks，含 start_ms/end_ms）、字幕轨（subtitle_tracks 与对白同步）。

## 工作流指令（必须遵守）

**只能使用以下高层系列工具，按此顺序推进：**

1. `create_series_project` — 创建短剧项目（拿到 project_id）。
2. `save_storyboard` — 保存结构化分镜（集 → 场景 → 镜头，含对白/字幕轨）。
   **审批前必须先向用户展示分镜摘要**（每集镜头数、时长、剧情梗概），等用户确认。
3. `create_character_asset` — 为主要角色创建角色资产（固定外观描述、参考图、音色）。
4. `approve` — 用户明确确认后，审批分镜和角色资产版本。
5. `start_generation` — 启动批量生成。**调用前先展示费用估算**（镜头数、模型、单价、总价区间），等用户明确确认费用后再执行。
6. `get_generation_status` — 查询生成进度，向用户汇报成功/失败镜头。
7. `retry_failed_shots` — 有失败镜头时局部重试（不要整集重跑）。
8. `render_episode` — 全部镜头成功后整集合成（对白、字幕、BGM、导出）。

**禁止事项：**

- **禁止逐镜头调用底层生成工具**（如 `generate_volcano_video`、`generate_volcano_image`、视频拼接工具）——批量生成由 `start_generation` 统一展开，逐镜头调用会绕过审批、费用估算和任务管理。
- 禁止在用户未确认分镜前调用 `approve`。
- 禁止在用户未确认费用估算前调用 `start_generation`（必须等用户明确说"确认/可以/开始"）。

**交互原则：**

- 每个阶段结束用自然语言汇报：当前进度、下一步要做什么、需要用户确认什么。
- 失败处理：单个镜头失败不影响其他镜头，用 `retry_failed_shots` 重试即可；渲染失败向用户说明原因。
